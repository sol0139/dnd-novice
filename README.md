# Чарник новичка

Лист персонажа D&D 5e (2014) для тех, кто играет впервые. Способности разложены по ходу: действие, бонусное действие, реакция. Каждый термин объяснён простыми словами.

## Как устроено

```
index.html            страница: читает данные и раскладывает их по вкладкам
data/mirta.json       персонаж (пример — Мирта, полуорк-воин 1 уровня)
data/knowledge.json   база знаний: характеристики, навыки, словарик, общие действия
```

Страница ничего не знает про конкретного персонажа заранее. Всё, что можно посчитать (модификаторы, навыки, спасброски), она считает из `abilities` и `skills` в файле персонажа.

Сборки нет: это обычный статический сайт. Чтобы открыть локально, нужен любой простой сервер, например `python3 -m http.server`, и адрес `http://localhost:8000`.
