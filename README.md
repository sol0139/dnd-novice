# Чарник новичка

Лист персонажа D&D 5e (2014) для тех, кто играет впервые. Мастер собирает персонажа в мастерской, игрок открывает его по короткой ссылке без регистрации. Способности разложены по ходу, каждый термин объяснён простыми словами.

## Как устроено

```
index.html            мастерская: вход через Discord и «Мои персонажи»
workshop.js           логика мастерской (Supabase: вход, список, создание, удаление)
sheet.html            лист персонажа: /c/код — персонаж из базы, /demo — пример
theme.css             общие цвета светлой и тёмной темы, шрифты
config.js             адрес базы Supabase и публичный ключ (не секрет)
vercel.json           адреса /c/код и /demo ведут на лист персонажа
data/mirta.json       пример персонажа и шаблон для новых
data/knowledge.json   база знаний: характеристики, навыки, словарик, общие действия
supabase/migrations/  таблицы и правила доступа в базе
```

Лист ничего не знает про конкретного персонажа заранее. Всё, что можно посчитать (модификаторы, навыки, спасброски), он считает из `abilities` и `skills` в данных персонажа.

## Где что живёт

- Справочник (`data/knowledge.json`) — в коде: он одинаковый для всех.
- Персонажи мастеров — в Supabase, таблица `characters`. Каждый мастер видит только своих. Игрок получает ровно одного персонажа по коду из ссылки.
- Хиты и потраченные способности игрока — в его браузере.

Сборки нет: это статический сайт. Локально его можно открыть любым простым сервером, но адреса `/c/код` и `/demo` работают только на Vercel.
