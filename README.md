# DnD Kids

Лист героя D&D 5e (2014) для тех, кто играет впервые. Мастер собирает персонажа в мастерской: из шаблона, в конструкторе, вручную или импортом из Long Story Short. Игрок открывает его по ссылке или QR-коду без регистрации. Способности разложены по ходу (действие, бонусное, реакция, работает само), каждый термин объяснён простыми словами.

Это не замена LSS: LSS — чтобы вести персонажа, DnD Kids — чтобы новичок за десять минут понял, как играть.

Сайт: https://dnd-novice.vercel.app

## Как устроено

```
index.html            мастерская: вход через Discord, «Мои персонажи», профиль
workshop.js           логика мастерской: список, шпаргалка стола, QR, профиль
create.js             шаблоны, конструктор с нуля, случайный герой
editor.js             ручной редактор: импорт из LSS с ситом, правка, пустой лист
builder.js            сборка листа из выбора мастера (числа, атаки, заклинания)
lss.js                разбор и сверка выгрузки Long Story Short
sheet.html            лист игрока: /c/код — из базы, /demo и /demo/nissa — примеры
theme.css             цвета светлой и тёмной темы, шрифты
config.js             адрес базы Supabase и публичный ключ (не секрет)
vercel.json           адреса /c/код, /demo, /preview ведут на лист
data/rules.json       расы, классы 1–4 уровня, предыстории, снаряжение
data/spells.json      89 популярных заклинаний 0–2 круга
data/templates.json   12 готовых героев
data/knowledge.json   словарик, навыки, подсказки «как играть»
data/dictionary.json  словарь для разбора LSS: оружие, доспехи, расы, классы
supabase/migrations/  таблица, правила доступа и лимиты бесплатной базы
```

## Где что живёт

- Справочники (`data/*.json`) — в коде, одинаковые для всех, в базе не лежат.
- Персонажи мастеров — в Supabase, таблица `characters`. Каждый мастер видит только своих, игрок получает ровно одного персонажа по коду из ссылки.
- Хиты, потраченные способности и заметки игрока — в его браузере.

Сборки нет: это статический сайт. Локально его можно открыть любым простым сервером, но адреса `/c/код` и `/demo` работают только на Vercel.
